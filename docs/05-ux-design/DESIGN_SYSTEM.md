# Design System

## Dirección visual

Mantener continuidad con Verdeo:

- protagonismo gastronómico;
- verde como identidad;
- fondos claros/neutros;
- fotografía de alimentos;
- espacio visual;
- jerarquía tipográfica clara;
- tono cálido.

El CRM no debe copiar literalmente la UI del sitio de marketing. Debe ser más compacto y operativo.

## Dos densidades

### Público

- emocional/gastronómico;
- touch targets grandes;
- navegación simple;
- fotografías;
- CTA visibles.

### Staff

- utilitario;
- alta legibilidad;
- tablas/listas;
- filtros;
- atajos;
- estados claros;
- mobile usable pero optimizado también para escritorio.

### Delivery

- extremadamente simple;
- botones grandes;
- mínimo texto;
- una acción primaria por etapa.

## Tipografía

La familia exacta debe extraerse de los assets/CSS oficiales antes de congelar tokens. No inventarla.

## Tokens

Definir:

- color brand;
- success/warning/error/info;
- backgrounds;
- border;
- text primary/secondary;
- spacing;
- radius;
- shadow;
- typography scale.

## Accesibilidad

- contraste AA;
- focus visible;
- labels reales;
- teclado en Staff;
- targets táctiles >= 44px;
- no depender sólo de color;
- estados con texto/icono.
