# Configuration Model

Todo lo que pueda cambiar por operación debe ser configuración o datos.

## SystemConfig

- timezone;
- currency;
- order public prefix;
- cycle cutoff defaults;
- locale.

## Geography

- cities;
- sectors;
- zones;
- WhatsApp account associations.

## Messaging

- accounts;
- default account;
- templates;
- automatic/manual per event;
- Meta template mapping.

## AI

- providers;
- models;
- capabilities;
- enabled;
- quotas;
- budgets;
- task routing;
- fallback policies;
- brand profile.

## Production

- surplus coefficient;
- export templates;
- kitchen recipient(s).

## CMS

- logo;
- palette;
- fonts;
- social links;
- contact data;
- SEO.

## Delivery

- route defaults;
- stop duration;
- message templates;
- navigation provider.

## Permissions

- roles;
- role permissions;
- user overrides.
